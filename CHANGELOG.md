# Changelog

## 0.1.0

- Initial release as **BundleBridge — Properties Resource Bundle Editor**.
- Group locale files in a shared editor with hierarchical keys and per-language text fields.
- Search, missing-translation filtering, add, duplicate, rename, copy and delete keys.
- New bundle and add-locale workflows; retain drafts and detect conflicting source edits.
- Configurable Java properties formatting and semantic round-trip tests.
